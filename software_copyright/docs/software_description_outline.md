# 无人机视角车辆小目标检测与评估分析软件 V1.0 软件说明书大纲

## 1. 软件概述
本软件面向无人机视角车辆小目标检测场景，提供数据准备、模型训练、目标推理、性能评估和结果导出等功能。系统围绕 EVD4UAV 数据集构建，可支持原始标注整理、切片增强、类别修复和 COCO 格式评估，适用于实验对比和成果材料整理。

软件基于 Ultralytics YOLO 基础框架完成二次开发，重点增强了小目标检测任务中常见的数据处理流程、训练推理封装和场景化模型配置。软件设计保持模块化，便于根据不同实验方案切换模型结构和评价指标。

## 2. 运行环境
软件建议运行在 Windows 或 Linux 系统环境中，具备 Python、PyTorch、OpenCV、NumPy、pandas、pycocotools、thop 等依赖。若使用 GPU 训练或推理，还需要安装与 CUDA 版本匹配的深度学习运行环境。

运行时需要准备图像数据、标注文件和模型权重文件。软件不内置训练数据和权重，用户应按自己的实验目录进行配置，并通过命令行参数指定输入输出路径。

## 3. 软件功能结构
软件功能分为数据集管理、标注格式转换、图像切片与标签同步处理、模型训练、目标检测推理、检测结果评估、指标统计与导出、场景化模型改进等模块。各模块之间通过统一的目录约定和配置文件进行衔接。

整体流程通常为先完成数据集整理，再进行模型训练和推理，随后使用评估模块统计 AP_S、AR_S、mAP、AP50、AP75 以及参数量、GFLOPs、延迟和 FPS 等指标，最终导出结果用于报告编写。

## 4. 数据集管理模块
该模块用于组织 EVD4UAV 数据集的目录结构和 YAML 配置，明确训练集、验证集和类别名称。用户可根据实际数据位置修改配置文件中的相对路径，不需要修改程序内部代码。

在数据集准备阶段，模块支持检查图像目录、标签目录和类别定义的一致性，减少训练前的数据组织错误。对于无人机航拍数据，统一的数据管理有助于后续训练、评估和结果汇总。

## 5. 标注格式转换模块
该模块用于将原始标注格式转换为 YOLO 需要的标准归一化文本格式。系统支持输入原始边界框坐标、类别映射和图像尺寸，输出规范化后的 `txt` 标签文件。

转换模块适合处理人工标注、旧格式标注或外部平台导出的坐标数据。通过统一标注格式，可以提高后续切片、训练和评估流程的一致性。

## 6. 图像切片与标签同步处理模块
该模块用于对高分辨率无人机图像进行滑窗切片，并同步裁剪目标标签。切片后的图像可保留包含目标的区域，也可按参数选择保留背景样本。

由于无人机视角下车辆目标通常较小，切片处理能够放大小目标在输入图像中的占比，从而改善模型对细粒度目标的学习效果。同步标签处理保证切片后标注仍然与图像位置匹配。

## 7. 模型训练配置模块
该模块用于封装 YOLO 训练流程，统一管理模型结构文件、预训练权重、数据集配置和训练超参数。用户可通过命令行指定 `imgsz`、`epochs`、`batch`、`device` 等参数。

训练配置模块支持不同的场景化模型版本，例如轻量化结构、P2 分支结构和带自适应特征融合的结构。通过配置文件切换模型，可以方便地比较不同方案对小目标检测性能的影响。

## 8. 目标检测推理模块
该模块用于对单张图片、图像文件夹或批量数据进行推理，自动输出检测框、置信度和保存结果目录。推理接口与训练接口保持风格一致，便于实验复现。

在无人机场景中，推理模块可用于对验证图像、测试图像或航拍切片进行目标检测演示。输出结果可进一步用于可视化、统计和报告整理。

## 9. 检测结果评估模块
该模块基于 COCOeval 对模型检测结果进行统一评价，支持生成 AP_S、AR_S、mAP、AP50 和 AP75 等常用指标。评估过程中会将 YOLO 标注转换为 COCO 规范，以保证指标计算方式一致。

除检测精度外，评估模块还会统计参数量、GFLOPs、单张延迟和 FPS，便于综合分析模型精度与效率之间的平衡关系。这些指标适合软著材料和实验对比表格使用。

## 10. 指标统计与结果导出模块
该模块用于将评估结果保存为 CSV 或 JSON 文件，并支持把配置参数与指标结果打包输出。导出内容可直接用于论文、软著说明材料或实验记录。

结果导出模块尽量保持轻量化，不依赖复杂界面。用户只需在命令行中指定输出路径，即可完成结果落盘和后续整理。

## 11. 场景化模型改进模块
该模块包含 NWD 小目标回归损失、自适应特征融合 ASFF、GhostConv/C3Ghost 轻量化模块以及 P2 分支等改进思路。它们围绕无人机视角车辆小目标检测的精度和效率需求进行设计。

不同改进模块可以在训练实验中按需组合，以形成多种模型变体。这样既能保留基础检测框架，又能体现针对具体场景的算法优化过程。

## 12. 第三方开源组件说明
软件在基础检测能力上参考并集成了 Ultralytics YOLO、PyTorch、OpenCV、NumPy、pandas、pycocotools、thop 等第三方组件。软件中的原创部分主要体现在业务流程、数据处理、训练评估封装和场景化改进模块。

第三方组件仅作为基础依赖使用，仍遵循其原始开源许可协议。软著材料中应将其与申请人独立完成的代码实现区分开来。

## 13. 软件操作流程
用户通常先配置数据集 YAML，然后执行标签转换或切片处理，接着选择模型配置并开始训练。训练结束后，可使用推理模块对图像进行检测，最后通过评估模块计算指标并导出结果。

在实际应用中，操作顺序可以根据数据状态灵活调整。例如，若原始标注已经是 YOLO 格式，则可直接进入切片与训练阶段；若需要统一类别，则先执行类别修复再进行后续处理。

## 14. 异常处理与注意事项
软件运行时应确保图像路径、标签路径和权重文件路径有效，否则训练、推理或评估可能无法正常执行。对高分辨率图像进行切片时，也应根据显存情况合理设置切片尺寸和重叠率。

导出结果和训练日志时应避免将大文件纳入软著材料目录。为保证材料整洁，建议仅保留代码、配置、说明文档和必要的结果摘要。
